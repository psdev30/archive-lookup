# Open in archive.ls

1. Open `chrome://extensions` in Chrome, `edge://extensions` in Edge, or `brave://extensions` in Brave.
2. Turn on **Developer mode**, click **Load unpacked**, and select the `archive-lookup` folder containing `manifest.json`.
3. Open an article and click **Open in archive.ls** in the extensions menu. You can pin the extension to the toolbar for one-click use.

The extension opens the archive.ls lookup in a new tab. Choose a snapshot if archive.ls lists multiple captures. If the article hasn't been captured, archive.ls may show a no-results or capture page.

The extension shares the current page address, including its query string, with archive.ls when you click. Use it on public article URLs.
