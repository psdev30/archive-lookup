# Open in archive.ls

## Store description

Look up an archived copy of the page you're viewing. Click the extension's toolbar button to open the current page's archive.ls lookup in a new tab. If archive.ls lists multiple captures, choose a snapshot. Snapshot availability depends on archive.ls.

## Single purpose

Open the archive.ls snapshot lookup for the current page when the user clicks the extension.

## activeTab permission justification

The extension uses activeTab to read the current tab's URL when the user clicks its toolbar button. It uses that address to open the corresponding archive.ls lookup in a new tab.

## Privacy policy text

Open in archive.ls reads the URL of the current tab when you click its toolbar button. It opens a new tab at archive.ls and includes the page address, including its query string, in that lookup. It strips the URL fragment before opening the lookup. Archive.ls receives this address and handles it according to its own practices. The extension does not store browsing history or send analytics to the extension publisher.
